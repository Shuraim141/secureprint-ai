This file is a Flask-based REST API backend for a system called SecurePrint AI Platform, which appears to manage secure industrial/3D printing workflows.
At a high level, it combines:
* Authentication & authorization (JWT tokens)
* AI-based print quality inspection
* Design file encryption and digital signing
* Supply-chain traceability
* Security monitoring
* Compliance reporting
* Dashboard metrics
________________


1. Application Setup
app = Flask(__name__)
Creates the Flask web server.
Configuration:
app.config.update(
    JWT_SECRET_KEY=...,
    JWT_ACCESS_TOKEN_EXPIRES=datetime.timedelta(hours=8),
    MAX_CONTENT_LENGTH=500 * 1024 * 1024,
    UPLOAD_FOLDER="/opt/secureprint/uploads",
)
Meaning:
Setting
	Purpose
	JWT_SECRET_KEY
	Signs JWT authentication tokens
	JWT_ACCESS_TOKEN_EXPIRES
	Tokens expire after 8 hours
	MAX_CONTENT_LENGTH
	Maximum upload size = 500MB
	UPLOAD_FOLDER
	Location for uploaded files
	________________


2. CORS
CORS(app, resources={r"/api/*": {"origins": "*"}})
Allows frontend applications from other domains to call the API.
Example:
fetch("http://localhost:5000/api/auth/login")
would work even from another website.
________________


3. JWT Authentication
jwt = JWTManager(app)
JWT = JSON Web Token.
Workflow:
Login
User sends:
{
  "username": "admin",
  "password": "Admin@SecurePrint2024!"
}
Server:
1. Verifies credentials
2. Generates token
token = create_access_token(...)
Returns:
{
  "access_token": "...",
  "role": "admin"
}
Later requests include:
Authorization: Bearer <token>
Protected endpoints use:
@jwt_required()
________________


4. User Store
USERS = {
    "admin": {...},
    "designer": {...}
}
Simple in-memory user database.
Passwords are stored as SHA256 hashes:
hashlib.sha256(password.encode()).hexdigest()
Example:
Admin@SecurePrint2024!
becomes:
5f6d...
Production concern
Comment already notes:
use PostgreSQL + bcrypt in production
because:
* SHA256 alone is not ideal for password storage
* bcrypt/Argon2 are safer
________________


5. Rate Limiting
Decorator:
@rate_limit(max_calls=10, window_seconds=60)
Protects endpoints from abuse.
Example:
POST /api/auth/login
limited to:
10 requests/minute/IP
Mechanism:
_rate_limit_store[key]
stores timestamps.
Old requests are removed:
if now - t < window_seconds
If limit exceeded:
429 Too Many Requests
________________


6. Audit Logging

Example entry:
{

/opt/secureprint/logs/audit.jsonl
JSONL = one JSON object per line.

* ISO 9001
* AS9100D
* Security investigations

7. Authentication Endpoint
POST /api/auth/login
@app.route("/api/auth/login")
Flow:
1. Read username/password
2. Hash password
3. Compare with stored hash
4. Create JWT token
Success:
{
  "access_token": "...",
  "username": "admin",
  "role": "admin"
}
Failure:
{
  "error": "Invalid credentials"
}
________________


8. AI Quality Inspection
POST /api/quality/inspect
Protected:
@jwt_required()
Accepts:
* image file
* printer_id
* layer_num
Example:
POST /api/quality/inspect
with image upload.
________________


Processing
Creates temporary file:
tempfile.NamedTemporaryFile()
Runs ML components:
from ml.defect_detector import ...
Pipeline:
image
  ↓
preprocess
  ↓
feature extraction
  ↓
classifier.predict()
Possible defects:
NORMAL
WARPING
STRINGING
LAYER_SHIFT
CLOGGING
Returns:
{
  "inspection": {
    "defect_class": "NORMAL",
    "confidence": 0.97
  }
}
________________


Fallback Mode
If ML model isn't available:
except Exception:
returns simulated results.
Useful for demos.
________________


9. Design Encryption
POST /api/ip/encrypt
Purpose:
Protect CAD/design files.
Allowed roles:
admin
designer
Checks:
if identity["role"] not in ("admin","designer")
Then:
DesignEncryptor()
encrypts:
design.stl
into:
design.stl.enc
Returns encryption manifest.
________________


10. Digital Signing
POST /api/ip/sign
Uses:
DesignSigner()
Purpose:
Verify:
* who created file
* file wasn't modified
Conceptually:
File
  ↓
Hash
  ↓
RSA Private Key
  ↓
Signature
Anyone can later verify signature using public key.
