This file implements a blockchain-inspired supply-chain tracking system for SecurePrint AI.
The goal is to prove:
* Who created a design
* Who manufactured a part
* Whether the part passed quality checks
* Whether a part is authentic or counterfeit
* Whether the historical records have been tampered with
Think of it as a mini Hyperledger Fabric simulation built on SQLite, with a real Hyperledger Fabric chaincode implementation included for production use.

5. Blockchain Linking
Every block references the previous block.
The code:
block_hash = SHA256(
    prev_hash +
    merkle_root +
    timestamp
)
Conceptually:
Block 1
Hash=A111


Block 2
Prev=A111
Hash=B222


Block 3
Prev=B222
Hash=C333
If someone changes Block 1:
A111 becomes X999
Blocks 2 and 3 become invalid.
This provides tamper evidence.
________________


6. Merkle Tree
Function:
_compute_merkle_root()
A Merkle tree compresses many transaction hashes into one hash.
Example:
TX1
TX2
TX3
TX4
Hashes:
H1
H2
H3
H4
Combined:
SHA(H1+H2)
SHA(H3+H4)
Then:
SHA(
  SHA(H1+H2) +
  SHA(H3+H4)
)
Result:
Merkle Root
Benefits:
* Fast verification
* Detects modifications
* Common blockchain technique

Strengths
✅ Hash-chained blockchain structure
✅ Merkle root verification
✅ Full audit trail
✅ Design traceability
✅ Part traceability
✅ Digital quality certificates
✅ Counterfeit detection
✅ Hyperledger Fabric migration path
✅ SQLite-backed local development mode
Important Limitations
⚠️ This is not a true decentralized blockchain in local mode; it is a blockchain-style ledger stored in SQLite.
⚠️ verify_chain_integrity() only checks hash links and does not recompute block hashes or Merkle roots.
⚠️ A new block is created for every transaction, which is inefficient compared with batching transactions.
⚠️ Fingerprints include a random nonce, so the same manufacturing inputs will generate different fingerprints each time.
⚠️ No cryptographic signatures are attached to transactions.
⚠️ No consensus mechanism exists in the SQLite implementation.
In short, this file is a supply-chain traceability and anti-counterfeit system that uses blockchain concepts (hash chaining, Merkle trees, immutable history) to track 3D-printed parts from design creation through manufacturing, certification, and authenticity verification.
