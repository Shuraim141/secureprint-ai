1. Authentication & API Connection ⭐
const API = 'http://localhost:5000';
let TOKEN = null;


async function doLogin() {
  const r = await fetch(`${API}/api/auth/login`, {
    method:'POST',
    headers:{'Content-Type':'application/json'},
    body: JSON.stringify({username:u, password:p})
  });


  const d = await r.json();


  if (d.access_token) {
    TOKEN = d.access_token;
    loadDashboard();
  }
}
Explanation
* Connects frontend to backend API.
* Sends username and password.
* Receives JWT access token.
* Stores token for secure API requests.
* Loads dashboard after successful login.

2. Navigation System ⭐
function showPage(id, el) {
  document.querySelectorAll('.page')
    .forEach(p => p.classList.remove('active'));


  document.querySelectorAll('.nav-item')
    .forEach(n => n.classList.remove('active'));


  document.getElementById('page-'+id)
    .classList.add('active');


  if(el) el.classList.add('active');
}
Explanation
* Controls page switching.
* Shows selected module.
* Hides all other pages.
* Creates a Single Page Application (SPA) experience.
________________


3. Dashboard Data Loading ⭐
async function loadDashboard() {
  const r = await fetch(
    `${API}/api/dashboard/stats`,
    {headers: authHeaders()}
  );


  const d = await r.json();


  document.getElementById('stat-inspections')
    .textContent = d.quality_control.inspections_today;
}
Explanation
* Retrieves real-time statistics.
* Updates dashboard cards.
* Displays inspections, defect rate, parts tracked, and events.
* Connects frontend to live manufacturing data.
